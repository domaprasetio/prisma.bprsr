# PRISMA
### Pendampingan Pascarehabilitasi dengan Integrasi Sistem Monitoring dan Asesmen

**PRISMA** merupakan aplikasi digital yang dikembangkan untuk mendukung pelayanan rehabilitasi sosial remaja di Balai Perlindungan dan Rehabilitasi Sosial Remaja (BPRSR), Dinas Sosial Daerah Istimewa Yogyakarta.

## 🎯 Tujuan
Meningkatkan efektivitas pendampingan pascarehabilitasi melalui digitalisasi asesmen, pemantauan perkembangan, dan pengelolaan data secara terintegrasi.

## ✨ Fitur Utama
- **Asesmen Digital:** Pencatatan hasil asesmen perkembangan remaja.
- **Monitoring Pascarehabilitasi:** Pemantauan perkembangan dan tindak lanjut klien.
- **Riwayat Asesmen:** Penyimpanan dan penelusuran hasil asesmen secara berkala.
- **Dashboard dan Rekapitulasi:** Penyajian statistik serta rekapitulasi hasil asesmen.
- **Pengelolaan Data Terminasi:** Pencatatan dan rekapitulasi status terminasi klien.
- **Integrasi Database:** Pengelolaan data melalui Google Spreadsheet dan Google Apps Script.
- **Akses Berbasis Peran:** Pengaturan hak akses berdasarkan jenis pengguna.
- **Layanan Digital:** Dirancang agar dapat diakses melalui komputer maupun perangkat seluler.

## 🛠️ Teknologi
- HTML, CSS, dan JavaScript
- Google Apps Script
- Google Spreadsheet

## 👥 Pengguna
Aplikasi PRISMA ditujukan untuk mendukung pekerjaan administrator, pekerja sosial, pimpinan, dan pengguna lain sesuai dengan hak akses yang diberikan.

## 🔐 Keamanan Data
Penggunaan aplikasi harus mengikuti ketentuan hak akses, kerahasiaan data, dan perlindungan informasi pribadi klien. Kredensial pengguna dan konfigurasi sensitif tidak boleh dibagikan secara terbuka.

## 🏢 Pengelola
**Balai Perlindungan dan Rehabilitasi Sosial Remaja (BPRSR)**  
Dinas Sosial Daerah Istimewa Yogyakarta

## 📌 Manfaat
PRISMA diharapkan meningkatkan efisiensi administrasi, ketepatan pemantauan, kesinambungan pendampingan, serta kualitas pelayanan rehabilitasi sosial remaja.
